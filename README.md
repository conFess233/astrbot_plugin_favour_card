本插件与原版 Favour Ultra 一起使用。好感度、关系与权限由原插件维护；本插件提供单人卡片和当前会话排行展示，并维护自己的素材与台词。

## 功能

| 能力       | 说明                                                         |
| ---------- | ------------------------------------------------------------ |
| PNG 卡片   | 960 × 600，浅色圆角卡片，显示昵称、数值、等级、关系与阶段进度              |
| 会话排行 | 浅蓝背景，头像、昵称、关系、阶段与实际好感度；高亮命令发送者，多页合并转发 |
| 随机图片池 | 每次从启用图片中等概率抽取，图片与台词分别抽取，允许连续重复 |
| 人工裁剪   | 超出 384 × 600 槽位时，固定框内拖动/缩放，确认后才上传成品   |
| 阶段多台词 | 新增、编辑、删除、启停、排序、按行批量添加；只抽取当前阶段   |
| 保留原文   | 格式不符、原生拒绝、依赖停用或渲染失败时，不生成虚假结果     |

## 快速开始

当前兼容目标为 **AstrBot >= 4.28.0、< 4.29.0 + Favour Ultra + aiocqhttp（QQ / NapCat OneBot v11）**。已核对 AstrBot 4.28.0 和 Favour Ultra 4.4.7 的公开源码接口；真实 Dashboard、QQ 收发与高并发部署验收尚未完成。

1. 安装并启用原版 [Favour Ultra](https://github.com/nuomicici/astrbot_plugin_Favour_Ultra)，确认它的单人查询正常。
2. 使用 AstrBot 插件管理的仓库安装入口，填入本仓库地址；也可手动安装。本项目未宣称已上架插件市场。
3. 默认使用 AstrBot 官方文转图服务，无需额外部署。需要自定义服务时，在 AstrBot 配置中设置 `t2i_endpoint` 并重启宿主；可参考 [自部署文转图说明](https://docs.astrbot.app/others/self-host-t2i.html)。
4. 打开插件详情的「好感度卡片管理」视图，上传图片、按阶段保存台词，点击模拟预览。
5. 在 QQ 发送 `/查询好感度`，正常情况下收到一张卡片；无法生成时仍收到原生文字。

**文转图服务：** 本插件直接复用 AstrBot 的渲染服务和端点配置，不额外限制端点，也不覆盖已有自定义设置。未自设端点时使用官方服务；单人卡片渲染失败或超时时保留原文，排行按配置重试渲染，耗尽后返回失败提示。渲染请求包含卡片数据、头像与图片素材，发送给当前使用的官方或自定义服务。

## 使用方法

| Favour Ultra 原生命令                                | 结果                               |
| ---------------------------------------------------- | ---------------------------------- |
| `/查询好感度`                                        | 查询自己，成功文本转换为卡片       |
| `/查询好感度 @某人`                                  | 由原插件判断权限后显示目标用户卡片 |
| `/查好感度`、`/好感度查询`、`/查看好感度`、`/好感度` | 使用当前原插件实际注册且启用的别名 |

| `/查询当前好感度` 及其原生别名 | 查询全部会话记录，按好感度降序生成排行 |
| `/查询当前好感度 2` | 仅发送第 2 张排行图，页码超出范围时取首／末页 |

前缀、命令改名、别名和 @ 参数由 AstrBot 原有指令匹配处理，本插件不额外注册同名指令。群聊/私聊查询开关、查询他人的权限和冷暴力拒绝由 Favour Ultra 控制。其余排行命令保持原有回复。

等级读取已启用 Favour Ultra 实例的当前配置；排行通过其运行实例的数据库接口读取记录，不另建好感度数据库。好感度数值与阶段名称默认采用下方六阶段预设，自定义时直接使用所选原色；未匹配这些名称时使用中性色。范围按整数闭区间计算；最高阶段显示 100%，等级空档或非法/重叠配置显示未定义等级，不推测阶段。

### 当前会话排行

在管理页「插件配置 → 排行头像」选择本地静态图片，确认方形裁剪后独立保存为 256 × 256 PNG，不占用角色图片池。支持缩放至 0.1～4 倍、拖动到原图范围之外，留白透明保存；头像在排行左上角以圆形显示。未设置或点击「恢复默认图标」时使用爱心图标。上传大小与像素限制沿用插件配置，取消裁剪或上传失败保留旧头像。

独立模式读取当前会话全部记录，共享模式读取当前适配器共享记录；沿用原生查询权限，不筛选当前群成员，不统计“近 30 天活跃”。副标题标明范围与总记录数。无记录时保留原生提示，不初始化或新增排行条目。

排行按实际好感度降序，同分按用户 ID 数值升序，序号连续。高亮命令发送者的已有记录，头像或实时昵称获取失败时分别使用占位图或用户 ID。阶段标签沿用管理页保存的颜色，关系另列小字并显示唯一标记。

不带页码时生成全部页面，全部渲染成功后发送；单页直接发图，多页放入一条合并转发，每个节点一张图。带页码时仅生成指定页面。图片引用遵循 `quote_source_message`，合并转发的引用放在首节点内。

仅重试失败页面的渲染，`retry_count=3` 表示首次失败后最多再试三次；耗尽后只发送“图片渲染失败，请稍后重试。”，不发送已生成的部分页面。单图和合并转发发送失败均记录日志，不自动补发，以免超时后重复发送。

### 阶段默认配色与台词

| 等级名称 | 主题颜色 | 默认示例台词 |
| --- | --- | --- |
| 极度厌恶 | 暗红色 | 你我之间，无话可说。 |
| 反感 | 灰紫色 | 还是保持些距离吧。 |
| 普通 | 青灰色 | 有何事？ |
| 喜欢 | 浅青色 | 若有闲暇，我愿听你说说。 |
| 亲密 | 蓝绿色 | 与你相处，倒也自在。 |
| 挚爱 | 淡金色 | 我既认定了你，便不会轻易改变。 |

默认颜色按实际阶段名称匹配，阈值仍使用 Favour Ultra 配置，不强加六个固定等级。每阶段可在管理页用取色器或 `#RRGGBB` 输入自定义数值与阶段名称的共同颜色；保存后下一次查询生效，卡片使用所选原色。未配置台词的上述阶段自动提供一条示例，可在「阶段设置」标签编辑并保存；已有台词、停用状态和手动清空不会被覆盖。阈值变化后仍需确认旧台词映射，不自动重新填入。以上为示例文案，并非官方原作台词。

## 配置

管理页的「插件配置」标签可编辑全部配置表字段，也可使用 AstrBot 原生配置页。管理页保存调用宿主配置保存接口，其余配置在下一次查询生效；`render_concurrency` 需重载插件，页面会持续提示。切换标签保留草稿，保存失败保留输入，版本冲突时先复制草稿再刷新合并。图片、阶段颜色与台词通过同一管理页维护。

| 配置键                 | 默认值     | 范围与作用                                                           |
| ---------------------- | ---------- | -------------------------------------------------------------------- |
| `enabled`              | `true`     | 启用卡片功能                                                         |
| `intercept_query`      | `true`     | 替换正常单人查询结果                                                 |
| `quote_source_message` | `true` | 发送卡片图片时引用触发查询的源消息；关闭时图片不引用，文字回退保持原生行为 |
| `bot_name` | `bot` | 1～40 字，排行标题及合并转发节点名称 |
| `ranking_page_size` | `80` | 每张 1～80 条，最多 5 列，末页按实际条数排版 |
| `retry_count` | `3` | 0～10 次，排行首次渲染失败后额外重试次数；不重试发送 |
| `show_initial_favour_card` | `true` | 无记录时显示初始卡片；关闭则首次查询保留原生文字 |
| `auto_initialize_on_query` | `true` | 首次授权查询自动创建缺失记录；关闭则不写入 |
| `initialize_only_if_missing` | `true` | 数据保护固定开启，不能关闭；不更新已有数值、关系或时间 |
| `theme`                | `default`  | V1 仅此模板                                                          |
| `character_name`       | `角色名`   | 1～40 字，角色名称                                                   |
| `image_pool_enabled`   | `true`     | 使用随机图池；关闭时使用空池兜底                                     |
| `show_user_id`         | `false`    | 显示 QQ 号                                                           |
| `show_relationship`    | `true`     | 显示原生关系文本（包含唯一标记）                                     |
| `show_progress`        | `true`     | 显示阶段进度与下阶段距离                                             |
| `enable_level_quote`   | `true`     | 显示当前阶段台词；关闭时隐藏                                         |
| `image_pool_limit`     | `50`       | 1～200 张；降低上限不删除已有图片，仅限制新增                        |
| `upload_max_mb`        | `10`       | 1～20 MB，原图浏览器检查及上传成品后端检查                           |
| `upload_max_pixels`    | `24000000` | 230400～40000000，浏览器解码前检查原图像素；后端成品固定为 384 × 600 |
| `empty_image_fallback` | `fallback` | `fallback` 使用自带中性占位图；`hide` 隐藏立绘                       |
| `empty_quote_fallback` | `hide`     | `hide` 隐藏台词；`default` 使用 `default_quote`                      |
| `default_quote`        | `""`       | 最多 120 字，仅默认句模式使用；不会借用其他阶段台词                  |
| `allowed_groups`       | `[]`       | 群号字符串列表；空列表不限群，私聊不受此项限制，原插件权限仍适用     |
| `render_timeout_ms`    | `10000`    | 1000～60000 毫秒，包含排队等待，单人卡片超时保留原文，排行每次尝试独立计时 |
| `render_concurrency`   | `2`        | 1～4，修改后重载插件                                                 |

首次查询初始化与卡片显示独立：即使关闭 `intercept_query` 或 `show_initial_favour_card`，开启 `auto_initialize_on_query` 仍会初始化缺失记录；关闭 `enabled` 或群聊不在 `allowed_groups` 中则不参与初始化。只处理原插件已授权的成功单人查询，权限拒绝、冷暴力拒绝和排行榜不会创建记录。

初始值使用 Favour Ultra 原生查询返回值，包含它的管理员初值和共享记录继承逻辑；管理员查询无记录的他人时，沿用原插件返回的值。会话键直接使用原插件的全局/会话模式。条件插入对并发请求幂等，不刷新已有记录的时间。渲染失败时已成功初始化的记录仍保留；初始化失败则保留原生回复。此适配按 Favour Ultra 4.4.7 源码接口验证，升级原插件后需联测。

人工裁剪确认与单人卡片失败保留原文是固定行为，不提供关闭它们的配置。本插件不提供自己的会话配置覆盖。

## 管理页面

入口为 AstrBot 插件页 → 本插件详情 → 好感度卡片管理。目标 4.28.0 从 `pages/card-manager/index.html` 扫描页面，新增页面或升级此修复后需重载插件并刷新 Dashboard；不要直接打开本地 HTML 文件代替宿主页面。仅已登录的 Dashboard 管理账户可以读写；Bot 管理员 QQ 号不等于网页管理身份，普通群成员发送图片不会自动入池。

**图片池：** 选择一张或多张静态 JPG、PNG、WebP。任一边超出槽位都会逐张打开裁剪窗口，固定 16:25 比例，拖动或方向键移动构图、滑块缩放；确认后才上传 384 × 600 PNG 成品。小图默认完整留白适配，也可主动裁剪。取消不上传，原图不保存在服务器。重复成品不会新增条目。上传后尝试展示实际卡片预览，服务不可用时保留已入池图片并提示预览失败。

页面提供操作通知、按钮加载状态和并发进度反馈；成功通知约 4 秒后收起，悬停或键盘聚焦时暂停；失败通知可手动关闭且字段旁保留错误。窄屏只展示最新通知，减少遮挡。取消确认不会提示成功。标签页、弹窗与列表使用轻量动效，并遵循系统“减少动态效果”设置。

**阶段颜色与台词：** 编辑颜色和台词后点击「保存此阶段」生效。切换标签保留草稿，保存失败保留输入。每条 1～120 字，每阶段最多 500 条。排序只改变管理列表顺序，不改变抽取概率。保存版本冲突时保留输入，请复制草稿后刷新并合并。

阶段键优先采用稳定 ID，否则采用 `min:max`。改名/改阈值时旧台词保留；同键阶段需确认重新保存，不同键可从旧阶段载入目标草稿并确认迁移。旧条目继续保留用于恢复。预览使用已保存配置、素材与台词及模拟数据，不代表真实用户好感度。

## 数据与安全

运行数据使用宿主路径工具定位，典型目录为：

```text
data/plugin_data/astrbot_plugin_favour_card/
├── images/             # 随机 ID 命名的裁剪成品，不含上传原图
├── image_pool.json     # 图片清单、启用状态、尺寸、哈希与模板
└── quote_pools.json    # 阶段颜色、台词、版本及保留的旧阶段
```

停用插件后复制整个目录即可备份，恢复时同样复制整个目录。升级插件源码不会覆盖此目录；不要只恢复清单而遗漏图片文件。

写入采用同目录临时文件与原子替换，失败保留原清单。损坏或不受支持的清单会报错，不自动重建。删除图片不可恢复，需要确认。后端校验身份、参数、真实图片格式、单帧、大小和固定尺寸，重新编码 PNG 去除原始元数据。官方管理页保证原图人工确认流程；服务端校验成品规格，不把客户端标记当作人工操作证明。

不额外保存查询日志，不调用 LLM。首次授权查询开启自动初始化时，会通过 Favour Ultra 的连接和模型向其数据库插入缺失记录；已有记录始终不做更新。昵称、关系和台词在 HTML 中转义。图片内嵌 Data URL，不请求外部素材或字体；渲染请求会把卡片数据和素材发给当前使用的官方或自定义文转图服务。
